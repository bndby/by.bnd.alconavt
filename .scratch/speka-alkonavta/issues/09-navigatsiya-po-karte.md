# Навигация по карте

Type: prototype
Status: open
GitHub: https://github.com/bndby/by.bnd.alconavt/issues/10

## Question

Как ощущается путь по карте: мир, страна, город, улица, список уровней бара?

Уже решено: тёмный фон, яркий неон, качественный пиксельный рисунок. Ярко только игровое: Минск и Зыбицкая, Витебск и Суворова, Москва и Патрики, бары на этих улицах. Остальная география тусклая. Все три улицы доступны сразу. Запуск открывает мир. Свободного зума нет, только эти четыре масштаба. Тап по бару открывает список уровней. Чужие тайлы карт в интерфейс не входят.

Нужен грубый прототип переходов. Узнаваемые контуры стран не требуются: достаточно схемы, по которой ясно, что ярко, что тускло и куда ведёт тап.
