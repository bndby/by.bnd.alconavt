# Как открываются уровни бара

Type: grilling
Status: resolved
GitHub: https://github.com/bndby/by.bnd.alconavt/issues/4

## Question

Как в баре открываются уровни?

Уже решено: тап по бару открывает список его уровней, и уже открытый уровень можно переиграть. Ранг задаёт, сколько уровней в баре, от 8 до 20. Все три улицы доступны с первого запуска.

Нужно решить, открыт ли сразу весь список или следующий уровень открывается победой в предыдущем.

## Answer

Решение согласовано с пользователем: последовательное открытие уровней внутри каждого бара и независимый прогресс всех баров.

### Порядок внутри бара

- С первого запуска в каждом баре открыт только первый уровень. Остальные открываются по порядку.
- Любая победа открывает непосредственно следующий уровень этого бара, если он есть. Одной звезды достаточно; требований к сумме звёзд для открытия следующего уровня нет.
- Поражение ничего не открывает.
- Пока персонаж жив, уже открытый уровень остаётся открытым и доступен для переигрывания. Худший победный результат не закрывает уровни. Последствия поражения и сброс при новой игре определены в [Как игрок ощущает опьянение](07-kak-igrok-oshchushchaet-opyanenie.md#answer).
- Повторная победа в более раннем уровне не позволяет пропустить непройденные: она открывает только следующий за ним уровень, который уже был открыт.
- Победа в последнем уровне завершает прохождение бара. Награда и её улучшение определены в [Звёздах уровня и выносливости за бар](02-zvezdy-urovnya-i-vynoslivost-za-bar.md).

### Независимость баров

Все бары на трёх игровых улицах доступны с первого запуска. Для начала игры в одном баре не требуется проходить другие бары или набирать звёзды в них.

Можно свободно переключаться между барами. У каждого сохраняются свои открытые уровни и лучшие результаты; прохождение одного бара не открывает уровни другого.

### Открытие и выносливость

Открытие уровня по прогрессу и возможность начать его при текущем запасе выносливости — разные условия.

Согласно [Трате и восстановлению выносливости](01-trata-i-vosstanovlenie-vynoslivosti.md), для начала любого уровня нужны живой персонаж и хотя бы одна единица выносливости. Нулевой остаток, его приоритет перед засчитыванием победы и сброс открытых уровней при новой игре определены в [Как игрок ощущает опьянение](07-kak-igrok-oshchushchaet-opyanenie.md#answer).

Отображение состояний уровней в списке разбирается в [Навигации по карте](09-navigatsiya-po-karte.md).
