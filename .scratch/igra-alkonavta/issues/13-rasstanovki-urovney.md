# 13: Постоянные расстановки всех уровней

**What to build:** У каждого из 208 уровней своя стартовая расстановка и проверенное решение. Игрок при повторе получает ту же головоломку. Все порции видны сразу. Сохранённое решение игроку не показывается.

**Blocked by:** 04: Прилавок на четыре и десять бутылок, 08: Плёнка уровней и незавершённый заход, 10: Карта мира, города и улицы

**Status:** done

- [x] В игре 15 баров и 208 уровней. Зыбицкая — 112, Суворова — 56, Патрики — 40. У пары «бар и номер уровня» одна сохранённая расстановка. Повтор и новый заход возвращают её же.
- [x] Число бутылок, число разных напитков и вместимость берутся из ранга. Ранг 1: уровни 1–4 — 4 бутылки, 2 напитка, вместимость 3; уровни 5–8 — 5 бутылок, 3 напитка, вместимость 3. Ранг 2: 1–4 — 5, 3, 3; 5–8 — 6, 4, 3; 9–12 — 7, 5, 4. Ранг 3: 1–4 — 6, 4, 4; 5–8 — 7, 5, 4; 9–12 — 8, 6, 5; 13–16 — 9, 7, 5. Ранг 4: 1–4 — 7, 5, 5; 5–8 — 8, 6, 5; 9–12 — 8, 6, 6; 13–16 — 9, 7, 6; 17–20 — 10, 8, 6.
- [x] В начале ровно две полностью пустые бутылки. Остальные заполнены до вместимости, в каждой минимум два разных напитка. У каждого выбранного напитка порций ровно на одну полную бутылку. Все порции видны с начала.
- [x] Напитки уровня выбраны из всего пула девяти без повтора одного вида. Крепкий напиток может стоять уже в первом баре. Во всём наборе каждый из девяти напитков встречается хотя бы раз.
- [x] Вместе с расстановкой хранится последовательность допустимых переливаний до победы. Её длина — норматив, самый короткий из найденных при подготовке. Абсолютный минимум не требуется. Расстановка без такой последовательности в набор не входит. Подсказки нет, решение на экран не выводится, норматив звёзды не считает.
- [x] Прогон сохранённого решения как череды тапов кончается победой за число ходов, равное нормативу. С запаса 120/120 персонаж после одного такого прогона жив.
- [x] Игрок доходит до любого бара с карты и открывает его уровни по порядку. Крайние прилавки читаются: четыре бутылки вместимостью 3 и десять бутылок вместимостью 6.
- [x] Проверка для каждой из 208 расстановок читает стартовый прилавок и прогоняет сохранённое решение через тот же модуль захода. Генератор, если он готовил набор, отдельной проверкой не обложен: в игре лежит готовый набор.
