# 02: Карточка напитка с собранной бутылки

**What to build:** Бутылка, заполненная одним напитком до вместимости, показывает его имя. Тап по имени открывает лист этого напитка, «Назад» возвращает на тот же прилавок. Тап по стеклу по-прежнему выбирает бутылку для перелива.

**Blocked by:** 01: Перелив на прилавке и победа уровня

**Status:** ready-for-agent

- [ ] Имя напитка видно только под бутылкой, заполненной им до вместимости. Разобранная бутылка имя теряет.
- [ ] Тап по имени открывает лист на экране уровня. Тап по стеклу той же бутылки выбирает её для перелива и лист не открывает.
- [ ] Лист одного напитка читается сверху вниз: рисунок бутылки, имя, крепость, культура употребления одним блоком, история, факты. Рисунок — один пиксельный силуэт без знака дома, залитый до горлышка цветом напитка, с лёгким статичным свечением того же цвета. Кадра производителя нет.
- [ ] «Назад» и системная «Назад» закрывают лист и возвращают на тот же прилавок. Расстановка, счётчик и выбор захода не меняются. Открытие и закрытие листа ходом не считаются.
- [ ] На плашке победы имя собранной бутылки всё ещё открывает лист и возвращает на ту же плашку.
- [ ] После ухода с прилавка лист недоступен: ни следующий экран, ни память открытых карточек его не держат. Снова открыть лист можно только новой сборкой этого напитка до вместимости.
- [ ] Проверка читает снимок: есть ли имя, открыт ли лист, совпадает ли текст блоков, та же ли расстановка после возврата.
