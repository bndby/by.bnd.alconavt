# 04: Прилавок на четыре и десять бутылок

**What to build:** Игрок играет и на коротком прилавке, и на длинном. Четыре бутылки стоят в один ряд, десять — двумя рядами по пять. Стекло большей вместимости чуть выше и шире и остаётся внутри своей клетки. Перелив и тап по собранной бутылке доступны на обоих краях.

**Blocked by:** 01: Перелив на прилавке и победа уровня

**Status:** resolved

- [x] Четыре бутылки стоят в один ряд. Пять и шесть бутылок стоят рядами по три. Семь, восемь, девять и десять стоят рядами по пять. Десять бутылок поэтому занимают два ряда по пять.
- [x] Вместимость на уровне одна у всех бутылок. Стекло вместе с горлышком не выходит из клетки. Горлышко общее, на одном уровне форма стекла одна.
- [x] На уровне из четырёх бутылок вместимостью 3 вокруг стекла остаётся запас. На уровне из десяти бутылок вместимостью 6 стекло доходит до края клетки. Вместимости 4 и 5 по высоте и ширине лежат между этими двумя.
- [x] На обоих крайних наборах порции различимы. Два тапа переливают, в том числе частично. Тап по имени собранной бутылки открывает лист, тап по стеклу выбирает бутылку.
- [x] Проверка читает снимок двух прилавков: число рядов, что перелив прошёл, что стекло описано как внутри клетки, с запасом при вместимости 3 и до края при вместимости 6.
