# 01: Перелив на прилавке и победа уровня

**What to build:** Игрок на портретном прилавке переливает порции двумя тапами и доводит уровень до победы. Плашка «Победа» остаётся на том же прилавке и показывает число ходов. Запас выносливости пока полон и от переливания не меняется.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Игрок видит бутылки портретного прилавка: порции стоят стопкой снизу вверх, свободные места видны над жидкостью.
- [ ] Первый тап по непустой бутылке выбирает её и не сдвигает. Повторный тап по ней снимает выбор. Тап по пустой бутылке без выбора ничего не выбирает.
- [ ] Второй тап по другой бутылке переливает верхнюю непрерывную стопку одного напитка, но не больше свободных мест. Перелитая стопка ложится в прежнем порядке, бывший верх остаётся верхом. Это один ход.
- [ ] Из трёх верхних порций при двух свободных местах уходят две, одна остаётся в исходной. Частичный перелив — один ход.
- [ ] Перелив допустим только в пустую бутылку или на тот же напиток сверху. Недопустимый второй тап не меняет расстановку и счётчик и оставляет выбор на исходной бутылке. Смешение не создаёт напиток.
- [ ] Победа наступает, когда каждая бутылка пуста или заполнена одним напитком до вместимости. Плашка «Победа» показывает число ходов. Ход — успешное переливание.
- [ ] Счётчик подписан «ходы». Подсказки и строки, которая объясняет жест, нет. Игра без звука.
- [ ] Проверка кормит модуль захода действиями игрока и читает снимок прилавка: порции, выбор, счётчик, плашку.
