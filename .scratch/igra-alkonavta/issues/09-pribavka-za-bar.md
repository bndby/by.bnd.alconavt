# 09: Прибавка выносливости за бар

**What to build:** Когда у каждого уровня бара есть звезда, бар поднимает текущий запас и потолок выносливости. Поздний повтор доплачивает разницу. Уже начисленное не уменьшается. Ход, который опустил запас до нуля, награду не даёт.

**Blocked by:** 08: Плёнка уровней и незавершённый заход

**Status:** resolved

- [x] Пока хотя бы у одного уровня бара нет звезды, бар ничего не начислил.
- [x] В момент победы, после которой звезда впервые есть у каждого уровня, прибавка равна среднему записанных звёзд всех уровней бара. Деление идёт по целым числам, без двоичного округления посреди расчёта. Дробная часть 0,5 и больше поднимает целое вверх. Начисляется весь округлённый результат: 1, 2 или 3.
- [x] Восемь уровней со звёздами 3, 3, 3, 3, 2, 2, 1, 1 дают среднее 2,25 и прибавку 2. Те же восемь, ставшие 3, 3, 3, 3, 3, 3, 2, 2, дают среднее 2,75, и бар доплачивает до 3.
- [x] Если повтор поднял округлённое среднее выше уже начисленного этим баром, разница приходит сразу после этого захода. Начисленное не уменьшается.
- [x] Каждая новая единица сразу поднимает и запас, и потолок на одну. Кто стоял на старом потолке, оказывается на новом. Доля пути к следующей восстановленной единице сохраняется.
- [x] Потолок равен 120 плюс сумма уже начисленных прибавок. Отдельного потолка сверху нет. Восстановление останавливается на текущем потолке.
- [x] Победа, после которой запас 0, звёзды не пишет, следующий уровень не открывает и прибавку не начисляет.
- [x] Проверка дочитывает звёзды бара через снимок запаса и потолка до прибавки, в момент первой полной победы и после повтора, который поднимает среднее.
