# 10: Карта мира, города и улицы

**What to build:** Живой игрок запускает игру на карте мира и доходит до бара тремя ступенями: мир, город, улица. Тусклые города остаются точками. «Назад» поднимает на одну ступень. «Новая игра» после гибели тоже открывает этот мир на 120/120.

**Blocked by:** 08: Плёнка уровней и незавершённый заход

**Status:** resolved

- [x] Живой запуск открывает мир на весь экран. Колонки ступеней и свободного зума нет. Страна отдельной ступенью не является. Своя пиксельная карта, без чужих тайлов.
- [x] Мир — кроп на города набора, север сверху, расстояния внутри кропа географические, города не раздвинуты. На кропе тихие границы Польши, Литвы, Латвии, Эстонии, Украины и граница Беларуси с Россией. Калининград, Сахалин, Чукотка, Камчатка, Новая Земля и крымский фрагмент на мир не входят.
- [x] Яркие точки с подписью и дробью «получено/всего»: Минск, Витебск, Москва. Получено — сумма лучших звёзд уровней баров города. Всего — три звезды на каждый такой уровень: у Минска 336, у Витебска 168, у Москвы 120. Тап открывает контур города.
- [x] Тусклые точки с подписью и без дроби: Могилёв, Гомель, Смоленск, Ленинград. Тап не меняет масштаб и сообщает, что у этого города уровни появятся позже.
- [x] На городе игровая улица — яркий штрих, прочие улицы тусклые. Зыбицкая — штрих около 400 м на северо-запад, левее и выше середины Минска. Суворова — штрих около 1,3 км почти на север в центре Витебска. Патрики на Москве — точка в верхней части основного массива.
- [x] Улица — контур, бары стоят на нём по порядку хода. Зыбицкая с запада на восток: Under, Койот, Zodiac, Рядом, Белый Налив, Горький, На дне, Матрешка. Суворова с севера на юг: Золотой лев, Марвин, «Damask» Kafe-Bar, Аптека бар. Патрики по контуру пруда: Киану, Bro&n, Зойка. Вода Патриков около 130×130 м, вокруг Малая Бронная, Большой Патриарший, Малый Патриарший и Ермолаевский.
- [x] Тап по бару открывает плёнку его уровней. Все пятнадцать баров доступны сразу, прогресс одного не открывает уровни другого. В каждом баре сперва открыт только первый уровень. Число карточек совпадает с рангом: ранг 1 — 8, ранг 2 — 12, ранг 3 — 16, ранг 4 — 20. Under и Койот — ранг 1, Zodiac и Рядом — 2, Белый Налив и Горький — 3, На дне и Матрешка — 4. Золотой лев — 1, Марвин — 2, «Damask» Kafe-Bar — 3, Аптека бар — 4. Киану — 1, Bro&n — 2, Зойка — 4.
- [x] «Назад» и системная «Назад» поднимают на одну ступень: с плёнки на улицу, с улицы в город, из города на мир. На мире кнопки «Назад» нет, системная «Назад» прогресс не меняет.
- [x] Над картой одна полоса: «запас/потолок», состояние и путь текущей ступени.
- [x] «Новая игра» с экрана гибели открывает мир, запас и потолок 120/120, в каждом баре снова открыт только первый уровень, звёзд и прибавок нет.
- [x] До постоянного набора у каждого бара уже можно открыть первый уровень. Постоянные расстановки всех номеров приходят отдельным тикетом.
- [x] Проверка читает снимок мира, города, улицы и плёнки после тапов и «Назад»: какая ступень, какие места яркие, какая дробь, какой бар открылся.
