# Алконавт

Портретная головоломка на Android. Игрок идёт по тёмной пиксельной карте в бары Минска, Витебска и Москвы, переливает порции на прилавке и собирает бутылки. Собранная бутылка называется своим напитком и открывает его карточку.

Интерфейс русский. Прогресс хранится на этом телефоне. Звука нет.

## Как играть

Карта — три ступени, без свободного зума: мир, город, улица. С мира открываются Минск (Зыбицкая), Витебск (Суворова) и Москва (Патрики). В баре уровни идут по порядку: победа открывает следующий.

На прилавке перелив — два тапа. Первый выбирает непустую бутылку, второй переливает верхнюю стопку одного напитка в пустую бутылку или на тот же напиток. Победа — когда каждая бутылка пуста или заполнена одним напитком до краёв.

Первая сборка бутылки в заходе тратит выносливость: чем крепче напиток, тем больше. Пока персонаж жив, запас возвращается по часам телефона. Ноль кончает игру. Звёзды уровня зависят от лишней траты, а не от числа ходов. Полный бар поднимает потолок выносливости.

## Поставить сборку

Готовый APK лежит в [релизах](https://github.com/bndby/by.bnd.alconavt/releases). Имя файла — `alconavt-0.Y.Z.apk`. Сборка отмечена как предварительная: так помечена каждая публикация, пока нет отдельного стабильного выпуска.

На телефоне нужен Android 8 или новее. Файл ставится вручную, не из магазина. Обновление поверх ставится тем же ключом подписи, и прогресс этой установки сохраняется. Сборка, собранная локально для отладки, подписана другим ключом и ставится как другое приложение.

## Выпуск

Пуш в `main` публикует APK, если в нём меняется игра, сборка, заметки или сам сценарий выпуска: каталог `app/` (кроме тестов), файлы Gradle, `CHANGELOG.md`, `.github/workflows/release.yml` и скрипт версии. Пуш только с правкой этого README выпуск не запускает.

Сценарий [`.github/workflows/release.yml`](.github/workflows/release.yml) прогоняет модульные тесты, подписывает release APK и кладёт его в GitHub Releases. Текст релиза — новые строки из [`CHANGELOG.md`](CHANGELOG.md). Строка начинается с уровня, дальше одна фраза для игрока:

```markdown
- patch: починка, нового поведения нет, прогресс читается.
- minor: новое поведение или место, прогресс того же мажора читается.
- major: установленный прогресс этой подписи больше не читается.
```

До первого мажора имя остаётся `0.Y.Z`. Почему так: [`docs/adr/0003-troyka-vypuska.md`](docs/adr/0003-troyka-vypuska.md).

Ключ подписи один на все выпуски и в репозиторий не входит. В GitHub Actions лежат секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Как их завести: `scripts/setup-release-keystore.sh`. Смысл постоянного ключа: [`docs/adr/0002-postoyannyy-klyuch-podpisi.md`](docs/adr/0002-postoyannyy-klyuch-podpisi.md).

## Локально

Нужны JDK 17 и Android SDK: платформа `android-35` и build-tools `35.0.0`. Каталог SDK — в `ANDROID_HOME` или в `local.properties` (этот файл в git не входит):

```properties
sdk.dir=/путь/к/Android/Sdk
```

Проверка поведения, без эмулятора:

```bash
./gradlew :app:testDebugUnitTest
```

Отладочный APK и установка на эмулятор или телефон:

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n by.bnd.alconavt/.MainActivity
```

Эмулятор — портретный телефон с образом API 35. Пример уже созданного устройства:

```bash
emulator -avd Medium_Phone_API_35 -no-snapshot
```

Если старый снимок не грузится, `-no-snapshot` поднимает систему заново. После загрузки те же команды `adb install` и `am start`.

Игра — нативный Android на Kotlin, без кроссплатформенных фреймворков. Правила захода живут в `GameRunModule`, оболочка в `MainActivity` только рисует снимок и шлёт тапы. Словарь терминов — [`GLOSSARY.md`](GLOSSARY.md).
