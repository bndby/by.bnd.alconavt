# Постоянный ключ подписи выпуска

APK на GitHub Releases подписывается одним и тем же ключом. Ключ создаётся один раз и хранится вне репозитория; в GitHub лежат только секреты, workflow новый ключ не выпускает. Сборка из Android Studio подписывается отладочным ключом и остаётся другим приложением.

Отладочный ключ, рождённый на раннере, на следующем запуске уже другой, и обновление поверх перестаёт ставиться. Google Play не используется: файл забирают с Releases. Смена боевого ключа оставляет прогресс в уже установленной сборке, потому что Android считает новый ключ другим приложением.
