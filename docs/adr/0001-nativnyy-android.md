# Нативный Android без фреймворков

Спека задаёт портретную игру на телефоне и шов между модулем захода и оболочкой, но не называет платформу. Игра собирается как нативное приложение Android: оболочка на Kotlin и Android SDK рисует снимок и шлёт действия в модуль. Flutter, React Native, Cordova, игровой движок и веб-оболочка не используются. Вторая платформа спекой не задана, а HTML-прототипы остаются образцами жеста, не каркасом приложения.

Модуль захода и прогресса по-прежнему не зависит от типов оболочки: тесты кормят его действиями игрока и часами телефона. Системная «Назад», сохранение на устройстве и часы — это API Android.
