# Тройка выпуска — совместимость прогресса

Имя выпуска — `MAJOR.MINOR.PATCH`. Патч чинит игру и не добавляет поведения. Минор добавляет поведение или место в игре, прогресс того же мажора читается. Мажор значит, что уже установленный прогресс этой подписью больше не читается. До первого мажора имя остаётся `0.Y.Z`, и на нулевой линии минор прогресс всё равно хранит. Долговременного сохранения партии в коде пока нет: правило задано заранее. Код версии Android — отдельное целое, оно только растёт и в имя не входит.

Счётчик `1.0.N` на каждый пуш отвергнут: номер должен говорить, читается ли прогресс, а не сколько раз собирали APK. Суффиксов вроде `-rc` нет. Неготовая сборка отмечена на GitHub как pre-release.
